# 工尺谱 · 新编

一个直接打开 `index.html` 即可使用的静态网页工具：输入歌词，为每个字录入工尺音和节奏，再转换为可编辑的简谱存档与简谱视图。

## 快速开始

### 直接打开

双击项目根目录的 `index.html` 即可使用，不需要启动服务器。

### 开发模式

```bash
npm install
npm run dev
```

### 构建检查

```bash
npm run build
```

## 页面流程

```text
输入歌词
  -> 编排工尺谱
  -> 工尺存档
  -> 转写简谱
  -> 简谱存档
  -> 简谱视图
```

工尺存档是工尺编排的来源。简谱转换后会生成独立的简谱存档；编辑简谱存档不会反向修改工尺存档。

## 工尺输入法

点击“输入音符”后，先选中一个歌词字，再输入拼音。完整拼音匹配成功后，工尺会加入当前字。

| 输入 | 工尺 | 基础简谱 |
|---|---|---:|
| `shang` | 上 | 1 |
| `chi` | 尺 | 2 |
| `gong` | 工 | 3 |
| `fan` | 凡 | 4 |
| `liu` | 六 | 5 |
| `wu` | 五 | 6 |
| `yi` | 乙 | 7 |
| `he` | 合 | 低音 5 |
| `si` | 四 | 低音 6 |
| `ye` | 一 | 低音 7 |

输入法顺序中，低音工尺优先列出：

```text
he 合 · si 四 · ye 一 · shang 上 · chi 尺 · gong 工 · fan 凡 · liu 六 · wu 五 · yi 乙
```

特殊输入：

```text
-  -> √ 豁腔
```

### 音区输入

音区箭头只写入工尺存档，转换简谱时再映射为高低音属性。

#### CapsLock：高音 `↑`

只有中音 1 到 7 支持高音：

```text
CapsLock + shang -> 上↑
CapsLock + chi   -> 尺↑
CapsLock + gong  -> 工↑
CapsLock + fan   -> 凡↑
CapsLock + liu   -> 六↑
CapsLock + wu    -> 五↑
CapsLock + yi    -> 乙↑
```

`合、四、一` 不支持 `↑`。

#### Shift：低音 `↓`

当前只支持中音 1 到 4 降为低音：

```text
Shift + shang -> 上↓
Shift + chi   -> 尺↓
Shift + gong  -> 工↓
Shift + fan   -> 凡↓
```

`合↓、四↓、一↓` 暂不支持，避免引入双排低音点。

## 节奏输入法

点击“输入节奏”，再点击当前字右侧的工尺字符进行选择。

| 键 | 内部节奏 | 存档字符 | 含义 |
|---|---|---|---|
| `1` | `、` | `、` | 正板 |
| `2` | `。` | `。` | 正眼 |
| `3` | `—` | `-` | 腰板 |
| `4` | `△` | `<` | 腰眼 |

每个工尺最多三个节奏符号。`Backspace` 或 `Delete` 删除当前工尺最后一个节奏；不使用 `0` 清除键。

## 工尺到简谱转换算法

转换分为“定位”和“视图渲染”两个阶段。工尺转换先固定简谱存档中的小节、拍位、音符和歌词位置；简谱视图只读取简谱存档，不重新猜测歌词位置。

### 1. 基础音高映射

```text
上 -> 1    尺 -> 2    工 -> 3    凡 -> 4
六 -> 5    五 -> 6    乙 -> 7
合 -> 低音 5
四 -> 低音 6
一 -> 低音 7
```

`↑` 和 `↓` 会转为简谱存档中的 `high` / `low` 信息：

```text
^5{字}  高音 5
_5{字}  低音 5
```

### 2. 小节和拍位

```text
、 / — -> 第一拍
。 / △ -> 第二拍
```

每个节奏符号都可以产生一个音位。一个工尺有多个节奏时，会在对应位置生成多个音位。

相邻特殊组合有例外：

```text
。— -> 按 。、 处理，后面的升级取消
、△ -> 按 、。 处理，后面的升级取消
```

### 3. 前延音

原来位置的音叫“板眼”，升级后向前延展的位置叫“前延音”。

```text
— -> 顿号升级
△ -> 句号升级
```

音符方面：

- 板眼位置保留
- 前延音位置也保留
- 音符前延不受它是第几个工尺影响

歌词方面：

- 默认歌词放在这个字的第一个工尺音下
- 只有第一个工尺本身标注 `— / △` 时，歌词才跟随前延音移动
- 后续工尺即使发生音符前延，也不能带走歌词
- 同一个歌词字的后续音歌词为空

例如：

```text
得 [尺@。] [上@] [四@-] [六@]
```

`四@-` 的音会参与前延，但“得”仍优先归属于第一个工尺 `尺`。

### 4. 后倚音 `√`

`√` 不单独占一个拍位，附属于它前面的实际音符。它会写入简谱存档中：

```text
2√{字}
```

视图会根据主音的音区和五声调式计算后倚音：

```text
1 -> 2
2 -> 3
3 -> 5
5 -> 6
6 -> 高音 1
```

简谱视图中以主音右上方的紧凑结构显示：

```text
    3
    =
    ╯
2
```

后倚音也会参考主音本身的高低音属性。

### 5. 歌词定位

每个歌词出现位置都有独立的内部 `rowId`，所以歌词中重复的字不会互相覆盖。

一个字多个工尺：

```text
春 [工@、] [尺@。] [合@]
```

简谱存档中只在该字第一个有效音下写歌词：

```text
3{春} 2{} 5{}
```

但所有音位都会保留。

## 存档格式

### 工尺存档

```text
---
format: gongchepu
version: 1
title: 未命名曲谱
meter: 2/4
style: 一板一眼
key: C
---

## 歌词

春风又绿江南岸。

## 工尺谱

### 第1句

春 [工@、] [尺@。]
风 [上@。]
```

存档中使用：

```text
△ -> <
— -> -
```

### 简谱存档

```text
---
format: numbered-notation
version: 1
meter: 2/4
source: gongchepu
---

## 简谱

### 小节1
第一拍: 2{春}
第二拍: 5{}
```

简谱存档是独立数据。修改它只影响简谱视图，不会修改工尺存档。

## 常用操作

- 点击歌词框：选中当前歌词字
- `Enter`：切换下一个字
- 上下方向键：切换上下字
- 输入音符模式：录入工尺
- 输入节奏模式：给选中的工尺录入节奏
- `Backspace` / `Delete`：删除当前工尺或节奏
- 点击“转写简谱”：根据工尺存档重新生成简谱存档
- 点击“工尺存档”：编辑并保存工尺存档
- 点击“简谱存档”：编辑独立的简谱存档
- 点击“导入存档”：导入 `.txt` 存档
- 点击“导出存档”：导出当前工尺存档
